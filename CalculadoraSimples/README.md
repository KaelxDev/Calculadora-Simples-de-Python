# 🧮 Calculadora Gráfica em Python

Uma calculadora gráfica desenvolvida em **Python**, utilizando a biblioteca **Tkinter**, com uma interface moderna e tema escuro.

O projeto foi desenvolvido para praticar desenvolvimento de interfaces gráficas, operações matemáticas e organização de aplicações desktop.

---

## 📌 Sobre o Projeto

A Calculadora Gráfica oferece operações matemáticas básicas, suporte à avaliação de expressões e histórico de cálculos durante a sessão.

O objetivo é proporcionar uma experiência simples, funcional e intuitiva, combinando recursos essenciais de uma calculadora com uma interface visual agradável.

---

## ✨ Funcionalidades

### 🔢 Operações Matemáticas

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- % Porcentagem
- 🔢 Números decimais
- 🧮 Avaliação de expressões matemáticas encadeadas
